# Agent 运行与会话契约

## 职责

- `AgentCoordinator`：串行处理界面命令、启动前台服务、维护任务终态。
- `AgentRunService`：Android 前台生命周期、通知和取消。
- `LedgerAgent`：装配一轮运行的依赖，可注入模型连接进行测试。
- `AgentRuntime`：Koog 流式循环、串行工具执行及检查点边界。
- `AgentContextBuilder`：将应用消息、协议记录和回执转换成模型上下文。
- `AgentRunSession`：按用户消息保存协议进度，并检查 run / attempt 所有权。
- `LedgerTools`：schema、只读查询和变更草稿工具。
- `AgentDraftActions`：用户确认、拒绝和准备撤销，不向模型暴露执行写入的能力。
- `AgentModelAccess`：DeepSeek 客户端生命周期、模型选择和图片能力。
- `LedgerPrompt`：账本规则和助手提示词。
- `AgentTraceRecorder`：流式展示与调试记录，不能用作模型上下文的来源。

## 三种历史

`AgentMessage` 是应用展示消息；`AgentTurnTranscript` 是协议记录；`AgentTraceEntry` 是可截断的过程展示。
协议通过独立编解码适配器保存 Koog 1.3 消息，包括 reasoning、tool call ID、参数、tool result、完成原因和元信息。
协议格式带独立版本。升级 Koog 时需要检查序列化兼容性，并扩展迁移及请求体测试，不能静默丢弃未知内容。

DeepSeek 思考模式携带 tools 时，后续轮次需要回传历史 reasoning。不能只重放最终回答，也不能从 trace 的展示摘要恢复协议。
当前完整回传文本协议，不自动压缩；图片仍只携带最近八张，并向模型说明省略。超长会话需要新开对话，后续压缩策略必须以完整工具交互为边界设计。
旧版历史没有原始协议，保留原聊天展示，将旧助手文本作为带说明的历史参考输入，不伪造 reasoning 或工具成功结果。

## 检查点与重试

每条完整 assistant 响应在执行工具前保存；工具串行执行，每个结果在下一个工具开始前保存。
流式响应尚未完成的片段仅属于 trace，不作为可恢复协议。请求中断后可以重新请求该响应。

- 已保存结果的工具不重放；仅恢复最后一批尚无结果的调用。
- 草稿 ID 与协议检查点一起记录。草稿已生成但工具结果尚未落盘时，恢复先清理该未提交草稿，再执行缺失调用。
- 最终 assistant 已落盘、界面完成状态尚未落盘时，直接恢复最终回答。
- 用户改发新请求时，不继续上次未完成工具；在模型上下文中为缺失结果补充明确的中断错误，闭合调用关系。
- `runId` 标识用户任务，`attemptId` 标识一次执行尝试。旧流式回调、停止命令和失败处理不能修改新 attempt。
- 草稿写入与恢复不会自动入账。确认后的幂等回执和账本变更由 Room 同一事务提交；会话回写失败后重试确认不会重复记账。

## 查询与修改

查询只使用业务表的独立只读快照，并复制业务索引。修改、删除工具必须提供查询得到的 `updatedAt`。
准备草稿时检查该版本与快照、实时账本都一致；确认时再次检查。跨轮和恢复后的旧查询结果也不能覆盖新记录。

## 存储提交

`agent-conversation.json` 是版本化索引，`agent-conversation.json.sessions/` 保存会话正文的不可变版本。
先完整写入新正文，再原子替换索引，最后清理被替代的旧正文。索引提交失败时丢弃新正文，保留旧索引及内存状态。
流式更新只重写当前会话，不重写其他会话正文；未持久化的展示增量不重新生成历史列表。
旧的单会话 JSON 和整包 archive 均支持读取，首次持久化时迁移。

## 验证范围

`AgentSessionTest` 覆盖进程内存重建后的跨轮协议及实际 DeepSeek 请求 JSON、工具批次中断恢复、完整长结果、旧 attempt 隔离、最终检查点恢复、版本冲突和跨存储失败重试。
这些测试使用 Robolectric、假模型或 HTTP MockEngine，不代表已验证真实 DeepSeek 服务、Android 杀进程和设备前台服务时序。
